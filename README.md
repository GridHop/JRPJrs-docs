# Publish JRPJr's docs on GitHub Pages

1. In the GridHop GitHub account, create a **public** repository named `JRPJrs-docs`.
2. Upload **all contents of this ZIP** (not the enclosing folder) to the repository root on the `main` branch, preserving subfolders.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. Once GitHub finishes deploying, open https://gridhop.github.io/JRPJrs-docs/ and test the links.

Website title: **JRPJr's docs**. The site is independent of Notion.

The supplied DOCX paragraph text is reproduced in source order without editorial rewriting. Inline Word formatting may not be preserved.
